# Admin dashboard designs

Source files for the admin dashboard screens: Dashboard (`Main`), Inbox, Founders, Services, Customers and Settings.

These are Claude Design canvas files (`*.dc.html` plus `canvas.json`). They are design sources, not the production website, and they need the design canvas runtime to render. They are kept here so the team can review and reuse the layout when building the real admin.

See [docs/admin-dashboard.md](../../docs/admin-dashboard.md) for the written proposal. All names, numbers and phone numbers are placeholders.
