# Public website designs

Source files for the public website screens: Home (`Main`), Services, Request details and Team.

These are Claude Design canvas files (`*.dc.html` plus `canvas.json`). They are design sources, not the production website, and they need the design canvas runtime to render. All names, services copy and contact details are placeholders.

See [docs/website.md](../../docs/website.md) for the written proposal.
